# Sourcing & honesty disclosure (Day 55)
**Paper:** FastBEVFusion: Simple Multi-Modal Fusion for 3D Object Detection at 50 FPS - Sanitz, Gulsoylu, Frintrop, Wilms (Univ. of Hamburg), arXiv 2610.37153, submitted 2026-10-27, ROBOT2026.
**Read via:** arxiv.org/abs (abstract) + alphaxiv overview + arxiv.org/html summary (full-text summaries returned by a fetch tool; not the raw PDF).
**Paper-sourced:** uniform-depth image->BEV, semi-aligned BEV, single cross-attention (LiDAR=Q, image=K/V) + MLP + residual, 3-stage training (stage 3 = fusion-only with extrinsic noise), nuScenes val: R18 62.1 mAP / 65.9 NDS / 17 ms (59 FPS, RTX 4090), R50 63.4 / 66.8 / 41 ms; fusion ablation 63.4 / 31.1 / 15.7 mAP (xattn / concat / add); R18 latency split 6.5+4.7+2.8+3.1 ms; distorted calibration 66.8 -> 66.0 NDS.
**Caveats from the paper's own text/tables (as summarised):** "over 50 FPS" is R18 only (R50 ~24 FPS); the ablation is on semi-aligned features; competitor latencies are estimates from other hardware; Table V seems to swap mAP/NDS labels; val split only.
**This repo's own (NOT the paper's):** the synthetic world, 1-D camera strip, LiDAR/clutter model, all dimensions (C=32, 16x16 tokens, 4 heads), CenterNet-style toy head (the paper uses TransFusion), every number in results.json and the demo. One seed, 3,000 train / 800 test scenes.
**Honest findings:** (1) fusion helps over LiDAR-only (AP 0.705 -> 0.80-0.85). (2) On clean data plain addition/concat BEAT cross-attention here (0.848/0.853 vs 0.803); attention has ~2x the parameters and no parameter-matched control was run. (3) Under 2.5 deg extrinsic error addition/concat lose ~0.15 AP, cross-attention ~0.01 - the paper's robustness direction reproduces. (4) Stage-3 noise fine-tuning added only +0.003 AP clean-vs-no-stage-3: robustness comes from attention itself, not stage 3. (5) The toy camera has perfect azimuth alignment, so addition is unusually easy; the paper's real depth ambiguity is harsher. (6) Bug found: first xattn run collapsed to an all-zero heatmap; fixed with gradient clipping + lower LR and a key LayerNorm (so the reported xattn is not the same recipe as the baselines' lr).
**Demo:** one scripted 8-object drive (seed 7), not cherry-picked: final running F1 LiDAR-only 0.50, add 0.526, FastBEVFusion 0.533 - a modest gap; add-fusion produced 17 false positives vs 4 for FastBEVFusion.
