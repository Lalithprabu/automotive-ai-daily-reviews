# Sourcing & honesty disclosure (Day 57)
**Paper:** *Observability-Aligned Evidential Masked Pretraining for Reliable VRU Motion Prediction* (model name eCoMAE), arXiv [2610.39958](https://arxiv.org/abs/2610.39958). Listed on arXiv around 2026-10-29/30 (ID sits right after Day 56's 2610.39258, listed 2026-10-29); exact submission date NOT confirmed - the abs page was rate-limited.
**Read via:** the arXiv HTML page (summarised by the fetch tool). I did NOT read the abstract page, authors or comments, and did not read the paper myself end to end. Paper numbers below come from that summary.
**Paper-sourced:** Transformer encoder on visible tokens only + decoder with mask embedding; block-wise time-step masking (default rate 0.80); NIG head (mu, nu, alpha, beta) with var = beta(1+nu)/(nu(alpha-1)); observability alignment = inverse-variance-weighted visible-step mean consistency + evidence suppression 2nu+alpha <= cap (cap 2) + cosine representation consistency across mask views; default weights lambda_evi 1, lambda_reg 1e-2, lambda_mu = lambda_alpha 0.05, lambda_rep 0.10; IMPTC intention (straight/left/right/stop), leave-one-weather-out OOD; IMPTC OOD acc 0.7971 (Ti-MAE) -> 0.8068 (eCoMAE-M), OOD AURC 0.0718 -> 0.0648 (eCoMAE-L); supervised Transformer OOD acc 0.7676, AURC 0.1497; fine-tune forecasting MSE e.g. nuScenes 0.2514 vs 0.2678. Stated limitations: one primary benchmark, weather-only shift, fixed weights, forecasting is supporting evidence. Observed by me in the summary: Table 1 vs Table 3 values for the large model differ, ablation margins ~0.003 without variance.
**This repo's own (NOT the paper's):** the synthetic VRU world and its 3 weather environments; model size (d=64, 2+1 layers); mask rate 0.6 and block 3 (paper default 0.8; lower because with 2 views and L=32, 0.8 leaves almost no overlap-visible steps for the representation loss); 2 views; the reference pass is no-grad (my guess); l_NIG = standard Amini et al. NLL; lambda_rec = 1 (unspecified in paper); mean-consistency weight normalisation; Huber delta; all training hyper-parameters; every number in `checkpoints/results.json`. Trajectory forecasting fine-tuning is NOT implemented (classification only).
**Results (3 seeds, mean±std; 300 labelled / 6000 unlabelled windows; ID = clear+rain, OOD = fog held out):**

| method | ID acc | ID ECE | ID AURC | OOD acc | OOD ECE | OOD AURC |
|---|---|---|---|---|---|---|
| supervised | 0.995±0.002 | 0.003±0.002 | 0.000 | 0.888±0.034 | 0.090±0.031 | 0.028±0.017 |
| Ti-MAE-style | 0.994±0.003 | 0.004±0.002 | 0.001 | 0.902±0.020 | 0.075±0.019 | 0.027±0.012 |
| eCoMAE-style | 0.994±0.002 | 0.005±0.001 | 0.000 | 0.909±0.027 | 0.074±0.023 | 0.022±0.008 |

**Honest findings:** (1) ID is saturated (~0.995) for all methods - the toy is easy in-distribution. (2) The OOD ordering matches the paper's direction (eCoMAE best, supervised worst on acc and AURC) but every gap is within one seed std; with 3 seeds this is NOT evidence that the method works. (3) eCoMAE's ECE is not better than Ti-MAE here. (4) In the demo clip (one scripted fog 'left' pedestrian, default seed) both models are correct after onset, and the NIG epistemic trace does not spike at onset - it should not be sold as an OOD alarm. (5) The synthetic world was tuned once (noise/cue strengths) to open an ID-OOD gap, BEFORE any final method comparison; no per-method tuning was done.
