# Sourcing & honesty disclosure (Day 61)
**Paper:** *Trajectory Evaluation via Rollout-Free World Model for End-to-end Autonomous Driving* (Junzhe Wang, Jinqing Zhang, Qingjie Liu; Beihang University), arXiv [2611.05072](https://arxiv.org/abs/2611.05072). Code: https://github.com/Rupertail/RFWorld (Apache-2.0).
**What I could read:** the GitHub README (via fetch) and search-result titles. arxiv.org abs/html were rate-limited (HTTP 429) for the whole run, so I have NOT read the abstract text or full paper. I have no paper tables, ablations, losses, dimensions or hyper-parameters.
**Paper/README-sourced (only these):** rollout-free world model for trajectory evaluation in end-to-end driving; shared scene memory from camera, LiDAR, ego state and navigation; temporal supervision shapes the memory in training; candidate trajectories scored by sparse spatial readout; released ResNet-34 model reports 90.5 PDMS on NAVSIM-v1 navtest (12,146 scenarios); uses a 1,024-anchor trajectory vocabulary and anchor-PDMS training targets.
**Everything else here is mine, NOT the paper's:** the toy BEV world, the analytic PDMS-style scorer, the 256 constant-curvature anchors, all module designs (FiLM memory fusion, 16 learned memory queries, grid_sample readout, composed sub-score head, 2-channel future-occupancy aux head), the global-MLP baseline, all numbers below.
## Toy results (single seed, 3,000 training scenes, 14 epochs, ~6 min on 2 CPU cores, 400 held-out scenes)
| scorer | true PDMS of picked anchor (oracle 0.931, random 0.406, straight 0.616) | score corr. | closed-loop (100 eps x 14 steps) collisions / off-road / progress |
|---|---|---|---|
| sparse-readout scorer (RFWorld-style) | 0.882 | 0.965 | 4% / 43% / 45.3 m |
| global-feature anchor MLP ("old way") | 0.801 | 0.818 | 6% / 21% / 30.7 m |
| sparse readout, NO temporal aux loss (ablation) | 0.882 | 0.966 | 6% / 45% / 44.8 m |
**Read honestly:** (1) per-waypoint spatial readout beats a global anchor classifier in open-loop selection on this toy; (2) the training-time temporal aux loss showed NO measurable benefit here (0.8822 vs 0.8821), so the paper's claim about it is neither reproduced nor refuted; (3) in closed loop the sparse scorer drives further but leaves the road far more often (43% vs 21%) - the scorer only looks 3 s ahead and my toy has covariate shift (training ego poses are near the centreline, rollouts drift); (4) single seed, toy world, no NAVSIM - none of this says anything about 90.5 PDMS. The demo clip is real model output (not a mock); its scenario seed was picked for having a nearby vehicle, not for model success; in that clip the pick equals the true best in 0 of 16 frames (mean regret 0.092).
