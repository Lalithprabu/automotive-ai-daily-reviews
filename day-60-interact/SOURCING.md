# Sourcing & honesty disclosure (Day 60)
**Paper:** *INTERACT: Learning Interaction-Aware World Dynamics from Driving Videos for Autonomous Driving* (Zhan Chen, Songyan Zhang, Wenhui Huang, Zirui Li, Zhidong Wang, Qihang Huang, Shiyu Fang, Chen Lv; NTU / Tongji), arXiv [2611.02526](https://arxiv.org/abs/2611.02526), v1 submitted 2026-11-02.
**Read via:** an alphaxiv.org mirror summary of the abstract/page ONLY. arxiv.org abs/html/pdf were all rate-limited (HTTP 429) for this run. I have NOT read the full text, so no losses, dimensions, hyper-parameters or result tables of the paper are known to me.
**Paper-sourced (abstract level):** 3-stage framework; (1) recurrent slots group dense visual features into temporally structured scene entities without object annotations; (2) latent ego actions inferred from slot context + video transitions condition future-slot prediction; (3) slots + latent actions + predicted future slots are distilled into a trajectory planner that generates and selects trajectories; trained from unlabeled driving videos; evaluated on NAVSIM and nuScenes; claims state-of-the-art NAVSIM with better safety-critical collision metrics. **No numbers are available to me; none are quoted.**
**This repo's own (NOT the paper's):** everything concrete. The toy BEV world (IDM traffic + ego-reactive cut-ins), 5 action prototypes, privileged oracle cost, 7-slot Slot-Attention encoder with SAVi-style first-frame conditioning (added by me after unconditioned slots collapsed), spatial-broadcast decoder, 5-code Gumbel latent action head, 2-layer slot transformer predictor, planner = MLP scoring 5 *grounded* candidate actions (grounding uses a small action-labelled set, which the paper's latent actions do not need), distillation target = oracle costs, dense-CNN baseline, closed-loop evaluation.
## Result: the world model did NOT train successfully (CPU budget), 4 attempts
| run | change | open-loop MSE x1e3 (copy-last = 13.55) grounded-action | recon MSE x1e3 | closed-loop slot_full collisions / progress |
|---|---|---|---|---|
| 1 | baseline recipe | 14.05 (= action-blind, slots near-identical) | 14.1 | 39.3% / 59.6 m (same as always-keep) |

| 4 (final, in `checkpoints/`) | + black-image decoder init, weight 5x | 23.0 (action-blind 23.0) | 23.1 | 5.3% / 24.6 m (always-brake degenerate) |
Closed loop (300 fixed scenes, 10 steps): always-keep 39.3% collisions / 59.6 m; random 32.0%; **dense-CNN planner 8.7% / 48.9 m**; slot planners 5.3% / 24.6 m only because they brake almost always (agreement with oracle action 6.9%); greedy oracle 14.3% / 56.1 m (myopic, so the dense planner beats it on collisions).
**Conclusions I can and cannot draw:** (1) the code runs end to end and the 7 unit tests pass; (2) at this scale (about 20 min CPU, 800 synthetic episodes) unsupervised slot discovery did not converge, so the claimed benefits of object-centric future prediction and of action-conditioned prediction (action-blind = grounded in every run) are NOT reproduced or refuted; (3) the dense baseline is the best learned planner here; (4) the latent action head reached 47% purity vs the true prototype in run 4 (90% in run 1, which was a near-collapsed model, so purity alone is not a quality signal).
