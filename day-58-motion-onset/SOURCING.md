# Sourcing & honesty disclosure (Day 58)
**Paper:** *Open-World Object Motion Anticipation via Meta-Learned Semantic Adaptation* (Peterson, MacLin, Tabasso, How, Migdal, Brady, Padir; Amazon FTR / MIT / U. Iowa), arXiv [2610.38993](https://arxiv.org/abs/2610.38993). Listed ~2026-10-29/30 (exact date NOT confirmed: abs/HTML pages were rate-limited, only the PDF was fetched). It is a *warehouse robotics* paper, not a road-vehicle paper; I use it because it is a pure prediction problem (will a static object start moving within 3 s?) that transfers to parked-vehicle pull-out / kerbside pedestrian onset.
**Read via:** the PDF, summarised by the fetch tool. I did not read the full text myself; paper numbers below come from that summary.
**Paper-sourced:** per-object probability of being dynamic within H=3 s (speed>=0.1 m/s), trained with a proper scoring loss on a query set of static / just-seen objects; scene graph with DINOv2 (384->64) semantic embeddings, kNN k=5 within 10 m, relative position/velocity edges; persistent scene node; 2x GATv2 (4 heads) + per-node GRU (64-d) + MLP/sigmoid; episodic training with TBPTT 20 frames; embedding augmentations (jitter/split/merge/spread/scramble); IsaacSim warehouse training (200 sims), 7 hardware episodes; metrics BSS / PR-AUC / ECE(20 equal-mass bins). Reported hardware robot-view BSS 0.335 vs CWAE 0.154 / VLM (Claude Haiku 4.5) 0.168; PR-AUC 0.560 vs 0.235 / 0.294; ECE 0.013; w/o recurrency BSS -2.123; closed-loop 20 scenes: 0% collision, 5% fail-to-reach, 68.5 s vs All-Static 15% collision, 64.8 s; ~20 Hz (DINOv2-S 42 ms + GNN 4.1 ms). Stated limitations: ground-truth state inputs only (no detector front end), tiny hardware set, no full trajectory distribution.
**This repo's own (NOT the paper's):** the synthetic kerbside world (6 train classes, 3 novel classes, hazard model with hidden per-episode class mobility, global tempo and "queue-release" cue); 32-d synthetic embeddings with per-episode jitter (stands in for DINOv2 + the 5 augmentations); dense GATv2 written from scratch; feeding GRU memory back into the message passing (my guess); 450 training steps, batch 24, lr 2e-3, plain BCE; the class-frequency baseline (my analogue of the paper's CWAE comparator, not the same algorithm); the toy ego planner in the clip. No VLM baseline, no closed-loop navigation, no detector front end.
**Results (3 seeds, mean±std; 150 fixed val episodes, 150 novel-class episodes):**

| method | val BSS | val PR-AUC | val ECE | novel BSS | novel PR-AUC | novel ECE |
|---|---|---|---|---|---|---|
| class-frequency | 0.081 | 0.236 | 0.021 | 0.000 | 0.157 | 0.064 |
| stateless GNN | 0.086±0.005 | 0.250±0.005 | 0.015±0.006 | 0.012±0.009 | 0.189±0.009 | 0.041±0.011 |
| full recurrent GNN | 0.104±0.005 | 0.286±0.003 | 0.016±0.008 | 0.039±0.007 | 0.228±0.009 | 0.031±0.003 |

**Honest findings:** (1) Ordering matches the paper (recurrent > stateless > class prior) and the gaps exceed seed std, but they are small in absolute terms: onset is a stochastic hazard in my world, so the achievable BSS is low and I did not compute an oracle ceiling. (2) The stateless model does NOT collapse to a hugely negative BSS as in the paper (-2.1); mine stays calibrated, so that drastic ablation effect was not reproduced. (3) Class-frequency "novel" score is 0 by construction (falls back to the global rate). (4) Val and novel sets are fixed episodes, seeds vary only the training; the same eval episodes were used for every model. (5) In the demo clip (first seed >= 7 with >=3 onsets in frames 15-42; seed 10, not chosen for model success) the full model gives the star pedestrian only p~0.22 three frames before onset - the model is not sharp on single objects. (6) Synthetic world tuned by hand once, before the final comparison; no per-method tuning.
